# Data

This project keeps data file-based — no database is used yet. CSV is the
default raw/processed format; Parquet is reserved for future, larger
datasets where its compression and dtype-preservation actually matter.

- `raw/` — untouched source exports, kept under their original source
  filenames. Committed to git: they're small and are the project's source
  of truth (`tfl_daily_cycle_hires.csv` — TfL daily cycle hire counts,
  columns `date` and `number_of_bicycle_hires`; `england_public_holidays.csv`
  — England bank holiday dates and names).
- `processed/` — cleaned/validated data derived from `raw/` (e.g.
  gap-filled, deduplicated, type-checked). Generated by
  `src/bike_network_analytics/ingestion`. Not committed (regenerable).
- `features/` — model-ready feature sets derived from `processed/`.
  Generated by `src/bike_network_analytics/features`. Not committed
  (regenerable). Never hand-edited.

Directory structure for `processed/` and `features/` is preserved via
`.gitkeep`; regenerate their contents by re-running the relevant
ingestion/feature code once it exists.
